# Student Result Management System

A web-based platform built with PHP, MySQL, CSS3, and JavaScript for managing student academic scores and grades.

## Features
- User Authentication & Role-based Access (Student / Admin)
- Admin Dashboard for Creating, Updating, and Deleting Student Results (CRUD)
- Student Portal to view personalized academic grades
- Responsive Design for Mobile and Desktop Viewports
- Contact Form Message Management

## Setup Instructions
1. Import `schema.sql` into MySQL/MariaDB.
2. Update database credentials in `config/db.php` if needed.
3. Serve the application via Apache web server.
